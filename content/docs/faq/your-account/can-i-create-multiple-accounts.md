---
title: Can I create multiple accounts?
description: No - running more than one Salad account breaks the Terms and can get every account banned.
---

No. Creating or using more than one Salad account is a breach of our [Terms](https://salad.com/terms/chefs/), and can
result in all of the accounts being permanently banned.

If you cannot log in to your existing account, or have a concern about it, contact [Salad Support](/contact) rather than
creating a new one. One account can run on as many PCs as you like.

## Two PCs with the same machine ID

If you set up a second PC by cloning or imaging the Windows install of the first, both PCs end up with the same machine
ID. Salad then sees one machine reporting from two places, and jobs fail to be assigned to either. Fix this by
[creating a support ticket](/guides/your-pc/how-to-create-a-support-ticket) with the machine ID so support can split
them.
