---
title: How can I contribute to the Salad support docs?
description: These docs are open source on GitHub - how to suggest a fix, correct a page or add a new article.
---

These docs are open source. If you spot a mistake, something out of date, or a question that should be answered here,
you can fix it yourself: open an issue or a pull request on
[GitHub](https://github.com/SaladTechnologies/salad-kitchen-docs). The
[contributing guide](https://github.com/SaladTechnologies/salad-kitchen-docs/blob/main/.github/CONTRIBUTING.md) explains
the page layout and conventions.

If you would rather not use GitHub, tell us what is wrong on the [Salad Discord](https://discord.gg/salad) or by
emailing [Salad Support](/contact), and we will update the page.
