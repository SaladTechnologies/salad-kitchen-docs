These are the games and programs Salad treats as intensive. If one of them is running while you Chop, Salad may pause
GPU jobs until you close it. See
[Your GPU is temporarily disabled](/troubleshooting/degraded-state/gpu-temporarily-disabled) for what happens and how to
get your GPU back, and [Close games and other programs](/guides/getting-jobs/close-games-and-other-programs) for how to
avoid it.

The list was last updated on November 17, 2026. The file name is what a program shows as on the Details tab of Task
Manager.

If a program here is being detected by mistake, contact [Salad Support](/contact).
