When Salad detects one of the programs below running while you Chop, it pauses GPU jobs until the program is closed.
This is the full list as of November 17, 2026: 3138 programs and 3576 file names. The file name is what the program
shows as on the Details tab of Task Manager.

For what happens when a program is detected and how to get your GPU back, see
[Your GPU is temporarily disabled](/troubleshooting/degraded-state/gpu-temporarily-disabled). To avoid the pause, see
[Close games and other programs](/guides/getting-jobs/close-games-and-other-programs).

If a program on this list is being detected by mistake, contact [Salad Support](/contact).
