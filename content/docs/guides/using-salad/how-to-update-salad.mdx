---
title: How to update Salad
description: How Salad app updates are delivered and how to install one.
---

When a new version of the Salad app is available, Salad tells you with a desktop notification, as well as in-app
notification. Click **Update Now** to install it; the app restarts on the new version. **Learn More** opens the What's
New page with the change log.

<Callout type="warn" title="Job Progression">
  Updating the app can take a few minutes, and closes the app and all underlying processes. This means updating the
  Salad App will **stop any active workloads**, and Salad will need to find a new workload after the update is complete.
</Callout>

![update now button on windows notification](../../../../content/images/guides/using-salad/how-to-update-salad-1.png)

Updates are only offered for the [update channel](/guides/using-salad/salad-app-settings) you have selected. If an
update keeps failing, download the latest installer from the
[official sources](/guides/getting-started/downloading-salad) and run it over your existing installation.
