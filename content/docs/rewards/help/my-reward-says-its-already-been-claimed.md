---
title: My reward says it's already been claimed
description: What to do when a store reports that your Salad reward code has already been used.
---

First, make sure the code was not already redeemed on another of your own accounts, or by someone who had access to your
Reward Vault or email. Also check that you are entering it in the
[right place and region](/rewards/help/my-reward-code-is-invalid): some stores report a code from the wrong region as
"already used".

If the code has never been used by you, contact [Salad Support](/contact) with:

- the reward name and reward ID from your [Reward Vault](/rewards/help/reward-vault-and-redemption-codes),
- a screenshot of the page where you entered the code,
- a screenshot of the code you entered,
- a screenshot of the "already claimed" error.

Support will check the code with the provider and sort out a replacement if it was issued as already used.
