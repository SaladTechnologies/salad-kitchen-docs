---
title: My reward code is invalid
description:
  What to check when a game, gift card or subscription code from Salad is rejected, and what to send Salad Support if it
  still fails.
---

Most "invalid code" errors come from entering a valid code in the wrong place. Check these first:

1. **Right place.** The reward's name and description say where the code is activated (which store, launcher, app or
   website). A Steam key will not work on Epic, an Amazon.de card will not work on Amazon.com.
2. **Right region.** Many codes are region locked and only work in the
   [region stated on the reward](/rewards/help/what-region-is-this-reward-for).
3. **Typed correctly.** Copy the code from the [Reward Vault](/rewards/help/reward-vault-and-redemption-codes) with the
   clipboard icon instead of typing it. Watch for 0/O and 1/I/l mix-ups if you must type it.
4. **Base game owned.** DLC and expansion codes only activate on an account that already owns the base game.
5. **Right account.** Make sure you are logged in to the account you want the reward on before entering the code.

## Still invalid?

If the code is rejected in the right place and region, the code we delivered may be faulty. Contact
[Salad Support](/contact) with:

- the reward name and reward ID from your Reward Vault,
- a screenshot of the page where you entered the code, showing the code and the exact error message.

If the code is accepted but the reward then does not work (card declined, membership not active), see
[Problems using a reward](/rewards/help/problems-using-a-reward). Redemptions are final, so support cannot refund a
reward, but it can check the code with the provider and replace a code that was faulty on delivery.
